# Norm-fiber densities and relative traces in characteristic two

Baohua Li - preprint, version 2026-10-26.

- [Main paper](main.pdf): 40 pages.
- [Supplement](supplement.pdf): 36 pages.
- [Chinese visual overview](overview_zh.pdf): 22 pages.
- [Complete editable source and verification archive](source_and_verification.zip).

The current paper gives effective norm-fiber densities, uniform E-valued relative-trace estimates, the complete C9/C11 exception classification, and their affine companion-group interpretation.

Classical tools and earlier counting objects are credited explicitly. This is a research preprint, not an externally peer-reviewed article.
