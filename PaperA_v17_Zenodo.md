# Paper A v17: Zenodo deposit

**Norm-fiber densities and relative traces in characteristic two** — Baohua Li.

- Version: v17 (28 October 2026).
- DOI: [10.5281/zenodo.23721670](https://doi.org/10.5281/zenodo.23721670).
- Public record: [Zenodo](https://zenodo.org/records/23721670).
- Exact GitHub release: [paperA-v2026.10.28-v17](https://github.com/63331849121/yijing-mathematical-structures/releases/tag/paperA-v2026.10.28-v17).

This independent deposit contains the main paper (41 pages), supplement (36
pages), editable LaTeX, public research sources and raw logs, exact certificates,
selective Lean sources and check records, checksums, and license notices.
It is a research preprint; an external peer review is not claimed. The nine Lean
modules check selected interfaces, rather than all of Theorems 5.1 and 5.4.

The record is separate from the earlier Singer note (10.5281/zenodo.22731492)
and Paper F (10.5281/zenodo.22745836). Those records and the historical GitHub
tags remain unchanged. The fixed v17 release, its seven deposited files and its
original checksums are preserved byte for byte. The README and citation inside
that fixed release predate this later DOI assignment; this note supplies the
updated citation without repackaging the release.
